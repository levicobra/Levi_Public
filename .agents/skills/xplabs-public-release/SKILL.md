# Release public websites

Read [release checks](references/release.md) when preparing a release. Repository-root `DEPLOY.md` contains hosting details when needed; verify its older status claims against current GitHub and Pages state.

Standing release authority covers scoped commit, push, PR, merge, and live verification. Complete that workflow after relevant checks pass without requesting the same approval again. Stop only for genuinely missing identity/authority or materially different destructive work. Do not recreate hosting or alter private-site access as part of a routine public release.
