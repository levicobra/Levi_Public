# Choose the content source

Read only the branch relevant to the requested change. Paths are relative to the repository root. Run Python with an installed or bundled interpreter; the absence of a working `python` alias does not justify replacing maintained generators.

- **Company pages:** edit `sites/www/.../index.html`; company styles and behavior live in `sites/www/assets/site.css` and `site.js`. For shared company navigation/footer, edit `sites/www/index.html` and run `python tools/sync_nav.py` from the repository root. This generator does not edit games, learn, or mil. Keep the company additive-manufacturing-only, with aeroponics marked as a concept project.
- **Game pages:** edit `sites/play/index.html` and the relevant game detail page. The game marketing pages share `sites/play/assets/games.css`; their navigation is independent of the company shell. Check every affected game page when changing a common link. Preserve existing legal/support pages and distinguish promotional concepts from gameplay.
- **Learn and mil navigation:** update the definitions in `tools/sync_satellite_nav.py` and run it from the repository root. Its `xpl-` styles are independent of both the company and game layouts. Inspect the generated diff and rebuild mil/learn outputs below.
- **Benefits directory:** edit `sites/mil/directory_template.html`, `data.json`, or `guard.json`, then run `python gen_directory.py` from `sites/mil`. Do not hand-edit the generated `index.html`. Preserve the visible crisis line and crisis search interception. Browser-check rent, dental, suicide, and an unmatched term. A new external-link audit is separate from visual work. The legacy `linkcheck.py` contains old scratchpad paths and disables TLS verification; repair and review those settings before relying on it for a current audit. Do not advance an audit date merely because the page was regenerated.
- **Education:** read `sites/learn/README.md` for content work. Edit subject JSON and catalog sources, retain OpenStax attribution, and run `python tools/validate_content.py` then `python tools/build_index.py` from `sites/learn`. Rebuild after **any** change under `sites/learn/`, including navigation, so service-worker content version and precache update together. Preserve `sw.js` no-store headers and offline fallback. Browser-walk home → domain → subject → lesson and confirm lesson content renders.
- **Palette:** follow the current standards at the top of `HANDOFF.md` and `docs/website-guide.md`. Preserve dark charcoal/green manufacturing, independent dark violet games, learn's subject colors, mil's crisis-only red, and the light initiatives page. `tools/apply_themes.py` is a legacy string-based helper, not the current source for the new game stylesheet; do not run it as a blanket redesign step. Recompute contrast for changed pairs.

After a generator run, verify that every changed file belongs to the intended edit. Do not commit unrelated generated drift. Use the existing browser checks from `HANDOFF.md` section 8 and the release skill for affected production origins.
