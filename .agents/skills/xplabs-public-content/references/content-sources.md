# Choose the content source

Read only the branch relevant to the requested change. Paths are relative to the repository root. Run Python with an installed or bundled interpreter; the absence of a working `python` alias does not justify replacing maintained generators.

- **Company and games pages:** edit `sites/www/.../index.html` or `sites/play/index.html`. For shared www/play navigation, edit `sites/www/index.html` and run `python tools/sync_nav.py` from the repository root. For learn/mil shared navigation, update the corresponding definitions in `tools/sync_satellite_nav.py` and run it too. Its `xpl-` styles are deliberately independent of the www/play theme. Inspect the generated diff and rebuild affected mil/learn outputs below.
- **Benefits directory:** edit `sites/mil/directory_template.html` and/or `sites/mil/data.json`, then run `python gen_directory.py` from `sites/mil`. Do not hand-edit the generated `index.html`. Preserve the visible crisis line and crisis search interception. Browser-check rent, dental, suicide, and an unmatched term. Use `linkcheck.py` when the task includes external-link health; it performs external checks and is not needed for unrelated prose edits.
- **Education:** read `sites/learn/README.md` for content work. Edit subject JSON and catalog sources, retain OpenStax attribution, and run `python tools/validate_content.py` then `python tools/build_index.py` from `sites/learn`. Rebuild after **any** change under `sites/learn/`, including navigation, so service-worker content version and precache update together. Preserve `sw.js` no-store headers and offline fallback. Browser-walk home → domain → subject → lesson and confirm lesson content renders.
- **Palette:** inspect `tools/apply_themes.py` and `HANDOFF.md` section 6 before color changes. Preserve learn's subject colors, mil's crisis-only red, the light initiatives page, and shared www/play design structure. Recompute contrast for changed pairs.

After a generator run, verify that every changed file belongs to the intended edit. Do not commit unrelated generated drift. Use the existing browser checks from `HANDOFF.md` section 8 and the release skill for affected production origins.
