HOW WE WORK

Start simple.
Make it better.

  1. 01 / DEFINE

    Bring the problem.

    A sketch, photos, a CAD file, or the thing that almost works. We start with what it needs to do.

  2. 02 / MAKE

    Make it tangible.

    Set the scope, prepare the design, and make a physical version to inspect.

  3. 03 / REFINE

    Check the details.

    Review fit, finish, and intended use. Use what we learn to shape the next iteration.
